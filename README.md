# 🌍 AI-Powered Workforce Analytics Platform

A production-grade data engineering and analytics platform that analyzes global job market trends, salary intelligence, skill demand, and AI disruption across industries.

## 🏗️ Architecture
- **Data Pipeline:** Python ETL with Pandas + Polars
- **Database:** PostgreSQL Data Warehouse (Star Schema)
- **Analytics:** Advanced SQL KPIs & Business Metrics
- **Dashboards:** Power BI Executive Dashboards
- **Backend:** FastAPI REST APIs
- **AI Layer:** Prophet / XGBoost Forecasting

## 📁 Project Structure
- `data/` — Raw and processed datasets
- `etl/` — ETL pipeline scripts
- `sql/` — Analytics queries
- `api/` — FastAPI backend
- `ml/` — Forecasting models
- `dashboards/` — Power BI files

## 🚀 Getting Started
```bash
# Clone repo
git clone <your-repo-url>
cd workforce_analytics

# Create virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```
